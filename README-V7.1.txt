KILLA FITNESS V7.1 · Titanium X Training Edition

Extract the ZIP contents to the ROOT of your GitHub Pages repository (not a nested folder).
Keep your existing browser storage: workout history is held in localStorage under killa-fitness-v4.
Before updating, open More > Settings > Export complete backup.
After GitHub Pages deploys, close the app and reopen it. If the old version appears, use a browser hard refresh or clear only cached website files (not site data).

Start: Train > Build Workout > muscle group > mode > session length > Generate/Start.
Save a workout: Build Workout > Save as Program.
Existing custom programs are retained and accessible in Programs.

This is a functional upgrade, not a pixel-perfect recreation of the concept artwork.
